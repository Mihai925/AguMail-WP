# Security Policy

## Reporting a vulnerability

Please report security issues in the AguMail plugin privately by email to
**support@agumail.com**, with "Security" in the subject line. Do not open a
public issue or post on the WordPress.org support forum.

Include what you can of:

- the plugin version, and the WordPress, WooCommerce and PHP versions;
- the steps to reproduce, or a proof of concept;
- what an attacker could do with it.

We acknowledge reports within 5 business days, keep you informed while we
work on a fix, and credit you in the changelog unless you would rather not be
named.

## Supported versions

Security fixes go into the latest release on WordPress.org. Please update to
it before reporting.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Disclosure

We ask that you give us up to 90 days to release a fix before you publish
details. Security releases are marked "Security:" in the readme's changelog.
